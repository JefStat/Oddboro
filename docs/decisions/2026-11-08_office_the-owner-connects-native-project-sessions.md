- [office] **Decision (2026-11-08): the owner connects a native project session by its conversation and project, or says yes to an Odd's ask to connect a Claude Code session it found open.** The owner can use it in the office or share it with an Odd. An Odd's request waits for the owner to take it over, whatever the Odd's level, because the native client's tools run with the owner's permissions; the owner can let the one Odd a session is shared with send there without asking, behind a second warning, and that leave counts only while the Odd is at Act. The cap lives where a request is written and claimed (`requestProject`, `claimProject` in `packages/ledger/src/project-sessions.ts`); it supersedes the 2026-11-08 ruling that only a Draft request waits. In a chat with Advanced mode on, an Odd lists the open Claude Code sessions with `find_open_sessions` and asks for one with `ask_to_connect_session`; the owner's Connect has the office connect it and share it with that Odd (`/api/asks/[id]/session`, `approveSession`), which supersedes the 2026-11-08 ruling that only the owner starts a connection (decided 2026-11-24).
